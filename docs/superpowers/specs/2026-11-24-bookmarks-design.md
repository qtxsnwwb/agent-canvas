# 书签：把值得回头找的会话和步骤收起来

状态：已实现，0.4.0 发布
日期：2026-11-24

## 1. 目的

用户用这个程序是为了**回头找**（用户原话：“主要是回头找”）：某个会话里有一步当时怎么解决的、某个会话做过什么，过几天想找回来。现在只能靠检索（要记得原话）或者把 `#/s/<会话>/n/<节点>` 地址收进浏览器收藏夹；程序里没有“标一下”的地方，也没有一处列出标过的东西。

这是用户挑的五个新方向里的第四个（前三个是待处理页、子代理时间线、今天的用量；最后一个是两会话并排对比，另行设计）。方向名里的“批注”按用户的目的收窄为**书签上的一句备注**，不做长篇批注。

### 1.1 目标

- 在会话页上一下就能收藏**整个会话**或**某一步**（用户选的：两种都要）。
- 每个书签可以带一句备注（可不填），记下“为什么标它”。
- 一个“书签”页列出全部书签，能按文字筛选，点一下回到那个会话、定位到那一步。
- 书签存在服务的数据库里（用户选的做法 A），换浏览器、清浏览器数据、重建、升级都不丢。
- 会话或那一步找不到了（源文件被删、重建后对不上），书签照样列出，标明找不到，不悄悄消失。

### 1.2 不做的

- 不做长篇批注、富文本、标签分类、文件夹。
- 不把备注加进首页的全局检索（书签页自己能筛选）。
- 导出的文件（HTML / Markdown）不带书签和备注；导出的查看器里没有收藏按钮。
- 不同步到别的机器。

### 1.3 反目标

- 书签悄悄丢失或挂错地方（重建、升级、会话变化之后）。
- 标一下要好几步操作，或者书签页难找东西。
- 书签页把对话内容露出来，绕过页面上的“遮蔽”开关（备注不算对话内容，见第 4 节）。

## 2. 做法的选择

| 做法 | 说明 | 取舍 |
|---|---|---|
| **A. 数据库里单独一张表（用户选的）** | 新表 `bookmark`，不在重建清空的表里；标记时存一份当时的样子（会话标题、工具、项目、那一步的摘要和时间）；增删改接口；改动推送给开着的页面 | 重建、升级、换浏览器都在；会话或步骤没了也能显示；代价是改库结构、多写接口和测试 |
| B. 存在浏览器里 | 只改网页 | 换浏览器、清数据、服务换端口就丢，违背“以后回头找” |
| C. 存在 `meta` 表里一整段 JSON | 和待处理页的“知道了”同样存法 | 每改一条重写全部，越多越慢；没法高效查“这个会话标过哪些步”；书签只增不自动清理 |

## 3. 书签是什么

- 两种：
  - **会话书签**：指向一个会话。
  - **步骤书签**：指向会话里的一步（一个节点，包括子代理内部的步骤）。
- 同一个会话最多一个会话书签；同一步最多一个步骤书签。再点一次就是取消（见第 5 节）。
- 字段：
  - 指向：会话 id；步骤书签另有节点 id。
  - 备注：可空，最多 200 个字符（超出拒绝保存，页面提示）；去掉首尾空白，换行折成空格。
  - 标记时间、备注最后修改时间。
  - **标记时的样子**（快照）：会话标题、来源、项目 id、工作目录；步骤书签另有那一步的种类、工具名、一行摘要（和画布卡片上的标题同一种写法）、那一步的时间。快照只在标记时写一次。
- 显示时优先用会话和步骤**现在的**样子（例如会话后来改了名，显示新名字）；找不到时用快照，并标明找不到（第 6 节）。
- 节点 id 来自各工具原始记录里的 id，重建后不变，所以步骤书签按 (会话 id, 节点 id) 指向。

## 4. 书签页

顶栏加一项“书签”，打开 `#/bookmarks`：

```
书签（23）                                  [ 筛选：备注、标题、步骤…    ]

★ 步骤  修好 CI 超时的那一步                              11-22 14:05
        Bash · npm test -- --testTimeout=20000
        agent-canvas · Claude Code · “修 CI 超时”            [改备注] [删除]

★ 会话  第一次接 Qwen 的会话                              11-18 09:30
        agent-canvas · Claude Code · “接入 Qwen Code”         [改备注] [删除]

★ 步骤  （没有备注）                                       11-17 21:12
        Edit · src/store.ts   ⚠ 找不到这一步（重建后对不上），会话还在
        …
```

- 按标记时间倒序。
- 每行：种类（会话 / 步骤）、备注（没有时写“（没有备注）”）、标记时间；步骤书签显示那一步的摘要；然后是项目、来源、会话标题。
- 点一行：会话书签打开那个会话；步骤书签打开那个会话并选中、定位到那一步（和检索结果点进去一样，地址 `#/s/<会话>/n/<节点>`）。
- 筛选框：按备注、会话标题、步骤摘要、项目名做字面匹配（不区分 ASCII 大小写，不支持通配符），在页面里即时筛。**匹配的是页面上显示出来的文字**：遮蔽开着时，标题、摘要按遮蔽后的样子匹配，这样不能靠猜一个密钥去试出哪一行含有它（实现时的决定）。
- 改备注：在行内编辑，回车或离开时保存；删除：直接删，页面上给一个“撤销”（几秒内可恢复），不弹确认框。
- 没有书签时：一句话说明怎么标（“在会话页的工具栏收藏会话，在每一步的详情里收藏这一步”）。
- 遮蔽：会话标题、步骤摘要、工作目录按页面上的“遮蔽”开关处理，和其他页面一样。**备注不遮蔽**：它是用户自己写的话，不是对话内容；遮蔽了就没法在遮蔽开着时改备注（改的时候只能看到占位符，保存会把真实备注覆盖掉）（实现时的决定）。

## 5. 在会话页上标

- **会话**：会话页工具栏加一个按钮“收藏会话”；已收藏时显示“已收藏”，再点取消。
- **步骤**：每一步的详情（右侧抽屉）顶上加一个按钮“收藏这一步”；已收藏时显示“已收藏”，再点取消。
- 收藏后按钮旁出现一个备注输入框（可不填），回车或离开时保存；已收藏的书签在这里也能改备注。
- 已收藏的步骤在画布上有一个小星标。和异常标记一样**往上归**：这一步自己有卡片时标在它的卡片上；它被收在一轮、一个子代理、一段折叠或精简视图的一串里时，标在那张卡片上（概览视图默认只画轮和子代理，不往上归的话默认看不到星标）（实现时的决定）。时间线、瀑布图不画。
- 取消收藏（再点一次按钮）时，备注一并删掉；有备注时先在按钮旁提示“备注会一起删除”并给“撤销”，不弹确认框。
- 导出的查看器（HTML）里没有这些按钮和星标。

## 6. 找不到的时候

- **步骤找不到**（会话在，那一步不在了，例如重建后编号变了）：书签页这一行标“找不到这一步”，显示快照；点它打开会话，定位到快照时间附近的那一轮（找不到就打开会话本身），并提示“这一步已经不在了”。
- **会话找不到**（数据库里没有这个会话了）：标“找不到这个会话”，显示快照；点它不跳转，只提示。
- **会话源文件被删**（会话还在库里，标着“源文件已删除”）：照常打开，不算找不到。
- 找不到的书签不自动删除，用户自己删。

## 7. 存储与接口

- 新表 `bookmark`：不在 `DERIVED_TABLES` 里，`rebuild` 和升级时的自动重建都不清它；`compact` 不动它。
- 建表用 `CREATE TABLE IF NOT EXISTS`，老版本打开新数据库时不受影响（它不读这张表）。
- 唯一约束：(会话 id, 节点 id)，会话书签的节点 id 为空串（或等价的唯一表示），保证“同一处最多一个”。
- 接口：列出全部、新建、改备注、删除；按会话列出这个会话的书签（会话页用：工具栏按钮状态、抽屉按钮状态、卡片星标）。写接口只接受本页面发起的请求（和导出接口一样的来源检查）。
- 改动推送：开着的页面（书签页、同一会话的会话页）收到更新；可以复用 app 已有的全局会话订阅连接，消息名留给实现。
- 数量：不设上限；书签页一次列出全部（几千条以内页面要流畅，见测试）。

## 8. 文档

手册新增“书签”一节：怎么收藏会话和步骤、备注、书签页的筛选和删除撤销、重建和源文件删除后的样子、导出不带书签、书签存在数据库里（`agent-canvas` 的数据目录），换浏览器也在。

## 9. 测试要点

| 方面 | 要测的 |
|---|---|
| 存储 | 新建、改备注、删除；同一处重复收藏被拒或合并；备注 200 字上限、空白处理；`rebuild` 后书签都在；老数据库升级后有这张表 |
| 快照与现状 | 会话改名后显示新名字；步骤不在时显示快照并标“找不到这一步”；会话不在时标“找不到这个会话”；源文件删除的会话照常打开 |
| 页面 | 书签页排序、筛选（备注、标题、摘要、项目名；遮蔽开着时按遮蔽后的文字匹配）、改备注、删除和撤销、空状态；遮蔽开关作用于标题、摘要、工作目录，不作用于备注 |
| 会话页 | 工具栏按钮、抽屉按钮的状态和切换；备注输入；星标在各视图里往上归到包含它的卡片（轮、子代理、折叠、精简的一串）；查看器里没有按钮 |
| 推送 | 一个页面收藏后，另一个开着的书签页和同一会话页更新 |
| 安全 | 写接口拒绝别的来源发起的请求 |
| 规模 | 5,000 条书签时书签页打开和筛选不卡（给出测得的时间） |
