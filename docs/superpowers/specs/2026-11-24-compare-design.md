# 两个会话并排对比

状态：已实现（分支 feat/compare；未发布）
日期：2026-11-24

## 1. 目的

用户用好几种编码代理，经常同一件事让两个工具各做一遍，或者同一件事做了两次。现在要比较只能开两个标签页来回切，统计页只有一堆会话的合计。这一页把**两个具体的会话**放在一起，回答：谁更快、更省、更顺，各自怎么做的，碰了哪些文件。

这是用户挑的五个新方向里的最后一个。用户说“按你自己的判断开始”，所以下面的取舍都是实现时的决定（标注“决定”的地方），用户看完可以推翻。

### 1.1 目标

- 从一个会话的页面一步进入对比：选另一个会话，打开对比页。
- 对比页并排列出两个会话的数字：总用时、轮数、步骤数、工具调用数、失败数、子代理数、token（新输入、缓存读取、输出）和来源。不列模型（决定：推导出的数据里没有模型字段，加上要改所有来源的解析并让全部数据重新推导，不值得）。
- 按工具名并排列出调用次数和失败次数（“Bash 12 次 / 20 次”）。
- 按轮并排列出每一轮的提示开头、用时、调用数、token，第 1 轮对第 1 轮。
- 文件：两边都碰过的、只有一边碰过的，各自读了几次、改了几次。
- 点任何一行能跳到对应会话的那一处。

### 1.2 不做的

- 不做逐步对齐的“diff”（两个工具的做法差别太大，逐步对齐出来的结果多半是噪声）。
- 不在一页里同时画两张画布（太挤、太重；要看细节就点进去）。
- 不比较三个及以上的会话。
- 不比较回复和思考的文字内容。
- 导出不带对比页。

### 1.3 反目标

- 对比页的数字和统计页、会话页对不上（同一个会话的 token、用时、调用数必须一致）。
- 打开对比页要把两个大会话的整张图都拉到浏览器里。
- 对比页把对话内容露出来，绕过“遮蔽”开关。

## 2. 做法的选择

| 做法 | 说明 | 取舍 |
|---|---|---|
| **A. 一页数字和表格（决定）** | 服务端用统计页已有的会话摘要和文件页已有的文件摘要，算出两边可比的数字；网页并排列表格，点行跳进会话 | 复用现成摘要，数字和统计页一致，大会话也轻；看不到画布，要看细节点进去 |
| B. 两张画布并排 | 在一页里放两个会话页 | 最直观，但窄屏放不下，两个大会话同时加载很重，比较还得靠眼睛 |
| C. 逐步对齐 | 把两边的步骤配对，标出增删 | 不同工具的步骤粒度不同，配对结果难以解读，成本高 |

## 3. 进入和选会话

- 会话页工具栏加“对比…”按钮，打开一个选择框（决定）：
  - 默认列出**同一项目**最近的会话（不含当前这个），按最近活动排；每行写标题、来源、最近活动时间（用首页已有的项目会话接口；不显示轮数，决定：那个接口没有轮数）。
  - 上面一个筛选框：在同项目列表里按标题字面筛；另有“在所有项目里找”，输入至少 2 个字时用首页检索已有的“会话”结果列出所有项目里标题等匹配的会话（决定：没有跨项目列会话的接口，复用检索比新加接口省）。
  - 选中一个就打开 `#/compare/<当前会话>/<选中会话>`。
- 对比页顶上有“交换左右”和“换一个”（重新打开选择框，换右边那个）。
- 地址可以直接收藏或分享给自己。
- 导出的查看器里没有“对比…”按钮。

## 4. 对比页

```
对比   [交换左右] [换一个]
                       左：修 CI 超时（Claude Code）   右：修 CI 超时（Codex）
总用时                  12 分 30 秒                     21 分 05 秒
轮数                    3                               5
步骤                    142                             260
工具调用 / 失败          58 / 2                          97 / 9
子代理                  4                               0
新输入 + 输出            1.2M                            2.0M
缓存读取                 18.4M                           3.1M

按工具                   左            右
Bash                    12（失败 1）   20（失败 6）
Read                    30             41
…

按轮     左                                 右
第 1 轮  “帮我修 CI…”  8 分 · 40 次 · 0.8M   “帮我修 CI…”  12 分 · 60 次 · 1.1M
第 2 轮  …                                   …
第 3 轮  …                                   （无）

文件                     左（读/改）    右（读/改）
两边都碰过  src/ci.yml    3 / 2          5 / 4
只有左边    …
只有右边    …
```

- 数字的口径全部沿用统计页和会话页（决定）：
  - 总用时 = 各轮用时之和（统计页的“工作时长”口径，进行中的轮算到现在，15 分钟无活动后停）。
  - 步骤 = 会话的节点数；工具调用、失败按统计页的定义（子代理内部的也算）。
  - token 按统计页的三类；没有 token 的来源写“—”。
  - 子代理 = 派出子代理的步骤数。
- 数字更好的一边加粗（用时短、调用少、失败少、token 少），只是提示，不下结论；两边相等或有一边是“—”时不加粗。
- 按工具：两边出现过的所有工具名，**按名字原样配对**（原决定：不同工具的工具名不同，例如 Claude Code 的 `Bash` 和 Codex 的 `exec_command`，这里不做对应表，两个不同工具比时多数行只有一边有数，手册写明），按两边次数之和从多到少；最多列 30 个，其余合成“其他”。上面草图里 Bash 两边都有，只是示意。
- 按类别（2026-11-27 加，放在按工具前面；按工具保留不变）：用一张工具名对照表（shared `toolCategory`）把两边所有工具（不受 30 个的限制）归成 跑命令、读文件、改写文件、搜索、子代理、联网、MCP 工具、其他，按这个顺序列出两边用过的类别，每格是调用次数（失败数）。MCP 工具按名字前缀认（`mcp__`、`mcp-`、`mcp_`）；对照表里没有的名字算“其他”。每类下面列出算进来的工具名（按两边次数之和从多到少，页面最多显示 6 个，再多写“等 N 个”），工具名照常按规则遮蔽。
- 按轮：按序号对齐；一边没有的那一轮写“（无）”。最多列 50 轮，超出时提示“只列出前 50 轮”。
- 文件：按两边次数之和排；路径按会话的工作目录显示为相对路径（和文件页一样）；两边的工作目录不同时按相对路径配对，并在标题旁注明“两边工作目录不同，按相对路径配对”。每组最多 100 个，超出写“还有 N 个”。
- 点一行：按工具 → 打开那个会话；按轮 → 打开那个会话并选中那一轮；文件 → 打开那个会话的文件面板、选中那个文件。
- 进行中的会话：数字随会话变化更新（最多每 5 秒一次，决定）。
- 遮蔽：会话标题、提示开头、文件路径、工作目录按页面“遮蔽”开关处理，用**规则**遮蔽，和待处理页、检索等跨会话的页面一样（决定）。会话页还会额外学习这个会话里出现过的值（例如某个只在这个会话里出现的密钥）；对比页不做这一步，手册写明：只有学习才认得出的值，在对比页可能看得到。
- 窄屏（手机宽度）：两列仍并排，每列写短；表格可以横向滚动，页面本身不横向滚动。

## 5. 数据

- 服务端一个接口：给两个会话 id，返回两边的对比数字（第 4 节的全部内容）。用统计页的会话摘要缓存（单个会话读取，`one()`）和文件页的文件摘要，不加载整张图到浏览器。
- 一个会话不存在：接口说明哪一边不存在，页面写“找不到这个会话”，另一边照常显示。
- 两边是同一个会话：允许，页面提示“两边是同一个会话”。
- 选择框的会话列表复用首页已有的项目会话接口和检索接口。

## 6. 文档

手册新增“对比两个会话”一节：怎么进入、每个数字的口径（和统计页一样）、加粗的含义、按轮和文件的配对规则、限制（不比较文字内容、不画画布、最多 50 轮 / 30 个工具 / 每组 100 个文件）。

## 7. 测试要点

| 方面 | 要测的 |
|---|---|
| 口径 | 每个数字和统计页对同一会话算出的一致（总用时、轮数、调用、失败、token）；没有 token 的来源 |
| 配对 | 按工具合并与“其他”；按轮对齐与“（无）”；文件三组、相对路径配对、工作目录不同的提示、上限 |
| 页面 | 加粗规则；交换左右；换一个；找不到的会话；同一个会话；遮蔽；窄屏不横向滚动 |
| 进入 | 选择框：同项目默认、所有项目、筛选；查看器里没有按钮 |
| 跳转 | 按轮跳到那一轮；文件跳到文件面板的那个文件 |
| 规模 | 两个各 10 万节点的会话：接口响应时间（给出测得值），浏览器不加载整张图 |
